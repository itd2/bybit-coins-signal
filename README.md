# Bybit Explosion Scanner

Realtime browser dashboard for scanning Bybit USDT markets for potential high-momentum moves.

## Features
- Bybit public API data
- 5m / 15m / 1h scanning
- EMA20/EMA50 trend
- RSI momentum
- Volume acceleration
- 24h price momentum proxy
- Explosion Score 0-100
- Responsive dark dashboard

## Run
Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Important
This is a market-analysis scanner, not a profit guarantee. The current static MVP does not claim to identify whales from exchange data. On-chain wallet tracking should be added with a dedicated blockchain/indexer backend in the next version.
